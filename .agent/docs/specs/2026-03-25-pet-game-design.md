# 虚拟宠物系统架构升级设计方案（2026-03-25）

> **目标**：将现有的单场景“观赏型”宠物，升级为一个高完成度、深度连贯的**真正的养成类游戏（类似 Tamagotchi 或 Pou）**。需要包含多场景结构、精细的组件拆分、丰富的视觉反馈和生命周期交互。

---

## 一、 系统架构拆解（模块化组件化）

为了实现“每一个交互都要设计得比较细节，拆分为多个组件进行构造”，我们必须摒弃当前“单个庞大的 `<PetPage />` 放天下”的做法。整个系统将拆分为两大层、五个核心模块：

### 1. 核心状态层 (Core Logic)
不与任何 UI 绑定，专职处理生命周期、数值衰减和行为限制：
- `usePetState` / Context: 统一管理 `hunger`, `hygiene`(清洁度), `fun`(心情/娱乐), `energy`(体力), 甚至增加 `age`(成长阶段)。
- 明确的动作 API：`feed(foodItem)`, `clean()`, `putToSleep()`, `play(gameResult)` 等。

### 2. 表现层组件 (View Components)
**A. `PetEngine` (引擎核心组件)**
只负责渲染宠物本身：合并我们现有的 7 个 SVG 精灵（idle, happy, sleeping, walking, dizzy, typing, notification），并根据当前状态（正在吃饭、正在洗澡、生病了）暴露给外界“当前播放哪个 SVG 动画”。

**B. `SceneManager` (场景管理器/多房间设计)**
宠物需要在不同的“房间”里进行不同的活动，以增强养成沉浸感。
我们可以设计经典的**多房间（Rooms）系统**：
  1. **起居室（Living Room）**：默认场景，包含地毯、沙发（或复古电视机）。宠物在这里发呆、走动、打字（触发 typing 动画）。
  2. **厨房（Kitchen）**：背景包含冰箱、餐桌。选择不同食物（汉堡、苹果），食物会摆在桌上，宠物走过去吃（播放 notification 发现食物 -> walking 走近 -> happy 吃完）。
  3. **浴室（Bathroom）**：包含浴缸。清洁度低时宠物会浑身发臭（加点苍蝇特效），点击清洗会触发浇水特效，宠物展示 happy 动画。
  4. **卧室（Bedroom）**：带窗户的房间。点击关灯后，整个画面变暗变蓝，宠物走到床边开始 sleeping。
  5. **游戏室/户外（Playground）**：我们目前的夜景星空大树，专门用于小游戏。

**C. `UIController` (UI叠加层)**
- **顶部 HUD**：属性进度条（饥饿、清洁、心情、体力）和硬币/得分。
- **底部抽屉（Action Menu）**：可滑出的交互面板。点击“吃饭”，不是直接加数值，而是切换到“厨房”场景并弹出食物清单；点击“洗澡”自动切到浴室。

## 二、 交互细节设计示例：喂食 (Feeding)

**当前的粗糙逻辑**：点击喂食 -> 数值+25 -> 闪两下粒子。
**升级后的精细逻辑 (Component: `<FeedingMinigame />` 或 `<FoodMenu />`)**：
1. UI 导航栏点击 🍎。
2. 镜头平移（或渐变切场）到**厨房场景 (Kitchen Scene)**。
3. 弹出“冰箱菜单”，里面有不同卡路里和价格的食物（例如：面包 🍖 恢复 10、牛排 🥩 恢复 40 且带粒子特效）。
4. 玩家拖拽食物到地上去。
5. `<PetEngine />` 侦测到前方有食物：
   - 播放 `notification.svg` (惊叹号闪烁：发现食物！)。
   - 切换为 `walking.svg`，平移走向食物。
   - 到达食物位置，食物消失（使用 CSS 爆裂动画）。
   - 播放 `happy.svg`，蹦蹦跳跳 2 秒。
   - 伴随音效（可选，或仅视觉反馈）。
6. 数值正式增加，并更新 UI HUD。

## 三、 场景构建技术：SVG 与纯 CSS 艺术

目前的 Canvas 渲染虽然可以做粒子，但对于“多个温馨房间的场景搭建”并不易于维护也难以做到完美的响应式矢量艺术。

**建议方案：**
抛弃重度 Canvas，完全采用 **SVG Scene + CSS Animation** 的方式来构建房间背景。这能与现有的 `clawd.svg` 精良的矢量风格完美契合。
我会用 React SVG 组件的方式绘制：
- `<LivingRoomScene />` (带摇晃台灯的复古客厅)
- `<KitchenScene />` (带可开关门冰箱的厨房)
- `<BedroomScene />` (一扇窗户，关灯后显示星空)
场景都是可交互的 React 组件对象，而不仅仅是背景图。
