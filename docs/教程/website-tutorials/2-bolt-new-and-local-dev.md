# 极速起航：用 Bolt.new 搭建 MVP 与本地二次开发实战

在上一章中，我们用“设计思维”理清了网站的定位，并选好了科技感的蓝紫配色。本章我们将利用最新的 AI 工具 **Bolt.new** 快速生成网站的原型，并一步步教你如何在本地搭建开发环境进行深度定制。

---

## 一、 什么是 MVP？用 Bolt.new 一键点亮网站

**MVP (Minimum Viable Product)** 意思是“最小可行性产品”。不要试图一开始就写出完美无缺的代码，先用最短时间做个能跑的“半成品”出来。

### 1. 投喂 Bolt.new 需求
1. 打开浏览器，访问 [Bolt.new](https://bolt.new/)。
2. 将我们的设计需求和配色直接发给它。**提示词范本**：
   > “我想用 React 编写一个个人网站，采用苹果风和响应式设计。我的名字是 zlcggb。网站色系为：Primary=#3c80fa，Secondary=#573cfa，Accent=#b63cfa。
   > 页面包含四个核心模块：
   > 1. 首页：连接机械与代码的桥梁，体现科技感。
   > 2. 作品集：展示大学期间的工程设计，体现工程思维的一致性。
   > 3. 进化之路：展示从机械到自学编程的个人成长时间轴。
   > 4. 技术实验室：展示我的具体教程和文章。”
3. 发送后，AI 会自动创建项目，从零开始安装包并当着你的面写出所有的 React 页面。

### 2. 在线一键发布
当 Bolt.new 编写完成后，点击右上角的 **Publish** 按钮，它会在几十秒内将网站上线，并给你生成一个可供公开访问的临时链接，例如 `zlcggb-portfolio.bolt.host`。复制这个链接，在手机或电脑浏览器中打开，你的个人网站就已经“点亮”了！

## 二、 落地本地：二次开发环境搭建三件套

虽然 AI 帮我们生成了初代原型，但要进行更高级的定制（比如接入我们自己的 Supabase 后端数据库），我们需要将代码下载下来在本地开发。

你需要安装以下三个核心开发工具：

```
+------------------+      +------------------+      +------------------+
|   1. Node.js     | ---> |      2. Git      | ---> |  3. Antigravity  |
|  (运行和编译环境)  |      |   (代码版本控制)  |      |   (AI代码编辑器)   |
+------------------+      +------------------+      +------------------+
```

### 1. Node.js — 网站的发动机
*   **作用**：在你的电脑上启动一个“本地服务器”，让你在不联网的情况下就能预览网站修改。
*   **安装**：前往 [Node.js 官网](https://nodejs.org/en/download) 下载 LTS 稳定版（对应你的 OS），一直点击“下一步”默认安装即可。

### 2. Git — 代码的时光机
*   **作用**：版本管理工具，防止代码写崩了无法撤销，并负责把本地代码安全提交到 GitHub。
*   **安装**：前往 [Git 官网](https://git-scm.com/install) 下载并安装。

### 3. Antigravity — 强大的 AI 辅助编辑器
*   打开本地项目文件夹后，信任项目，利用编辑器内置的 Vibe/Vibe 模式，直接用中文向 AI 发送需求或截图，AI 会自动修改本地文件，开发效率极大提升。

## 三、 本地运行与 Git 代码提交

### 1. 本地冷启动
在 Bolt.new 界面点击 **Download Project**，你会得到一个 `.zip` 压缩包。解压到本地文件夹，用编辑器打开该文件夹，然后在终端输入以下命令：
```bash
npm install     # 安装项目所需的零件依赖包
npm run dev     # 启动本地开发服务，在浏览器输入 http://localhost:5173 即可预览修改
```

### 2. 注册并配置 Git 仓库
为了能够管理代码，首先在本地初始化 Git：
```bash
git init
git config --global user.name "你的GitHub用户名"
git config --global user.email "你的邮箱"
```

### 3. 上传代码至 GitHub 库
在 GitHub 上创建一个空仓库，然后在终端执行：
```bash
git add .
git commit -m "feat(init): 初始化个人网站代码"
git branch -M main
git remote add origin 你的GitHub项目仓库链接
git push -u origin main
```

> [!IMPORTANT]
> **Git 提交失败或网络超时怎么办？**
> 如果你在国内拉取或推送代码遇到 GitHub 连接失败，可以通过配置代理命令解决。

例如，通过以下终端命令配置代理：
```bash
# 假设你本地运行了代理软件，端口为 7890
git config --global http.proxy http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890
```

需要清除代理时，运行：
```bash
git config --global --unset http.proxy
git config --global --unset https.proxy
```

## 四、 语法与思维转变：为什么我们要选择 React？

对于零基础而言，很多人纠结：**“我为什么要学 React，传统的 HTML 不是更简单吗？”**

我们可以做一个生动的比喻：

*   **HTML 是“地基和泥砖”**：每一次点击不同的导航菜单，浏览器都要向服务器重新请求一堆“砖头”，页面会发生刺眼的**白屏刷新**，且每次重新请求都有延迟。
*   **React 是“高科技装配房”**：你写的是组件（如同标准零件）。当用户点击导航时，只有“房间里的家具”（局部组件）会被替换，地基和外墙（导航、页脚）岿然不动。页面实现**零延迟的无缝切换**。

```
传统网页跳转：
点击按钮 ---> 浏览器清空白屏 ---> 重新下载整页 ---> 再次渲染 (体验割裂)

React 网页跳转：
点击按钮 ---> 仅替换中间的内容组件 ---> 其余部件不动 (丝滑无缝)
```

这种组件化思想，与机械设计的“标准零件库”（如螺栓、轴承可随处复用）有着异曲同工之妙。学好了 React 的组件化思想，你的软件开发架构能力将突飞猛进。
