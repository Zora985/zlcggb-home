# 经验沉淀：像素宠物角色换色系统（CSS Filter 方案）

## 问题场景

需要在只有一套 SVG 精灵（7 个状态文件）的前提下，支持用户选择不同角色/配色方案。

## 技术选型

| 方案 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| CSS Filter 换色 | `hue-rotate` + `saturate` 变换颜色空间 | 零新资源、即时生效、性能好 | 只换颜色不换造型 |
| Inline SVG + CSS 变量 | 将 SVG 内联为 React 组件，用 CSS custom property 控制 fill | 精确控颜色 | 7 个 SVG × 150+ 行动画 = 重构量巨大 |
| 多套 SVG 文件 | 为每个角色画 7 个独立 SVG | 完全不同造型 | 每新增角色 = ~7000 行 SVG |

**选择 CSS Filter** 作为 MVP，架构预留多套 SVG 扩展。

## CSS Filter 换色原理

原始角色身体色 `#DE886D`（HSL ≈ 16°, 63%, 65%）。通过 `hue-rotate(N deg)` 旋转色相环：

```
原色(16°) → +185° = 蓝(201°) → +105° = 绿(121°) → +265° = 紫(281°)
```

配合 `saturate()` 和 `brightness()` 微调饱和度和明度。

**注意：** `hue-rotate` 影响 SVG 中所有有色元素（包括特效粒子），但黑色（眼睛）不受影响（无色相）。

## 架构设计

```
characters.ts        → 角色配置（id, name, filter, colors）
usePetState.ts       → characterId 存储在 localStorage
PetEngine.tsx        → 接收 characterFilter 并应用到 <img> style
CharacterSelect.tsx  → Portal 弹窗选择 UI
PetHUD.tsx           → 调色板图标触发选择面板
Bedroom.tsx          → sleepHeadColor 适配被窝内头像颜色
Playground.tsx       → 游戏内角色同步应用 filter
```

## 扩展指南

### 添加新颜色变体

在 `characters.ts` 的 `CHARACTERS` 数组中添加新条目：

```typescript
{
  id: 'clawd-xxx',
  name: '名称',
  emoji: '🎯',
  description: '描述',
  bodyColor: '#HEX',                      // 预览色
  filter: 'hue-rotate(Xdeg) saturate(Y)', // CSS filter
  sleepHeadColor: '#HEX',                 // 卧室睡觉头色
}
```

### 添加全新角色造型

1. 在 `public/pet-sprites/` 下创建新文件夹（如 `kitty/`）
2. 画 7 个 SVG（idle, happy, walking, sleeping, dizzy, typing, notification）
3. 在 `CharacterDef` 中添加 `spriteFolder` 字段
4. 修改 `PetEngine` 的 `SPRITES` 查找逻辑，按 `spriteFolder` 加载不同路径
