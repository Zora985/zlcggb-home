# 经验沉淀：圣诞树“标题/图片可编辑”与缓存策略（刷新清空）

## 需求特点
- 用户可以在控制面板里编辑：
  - 主标题
  - 副标题（成树态 / 星尘态）
  - 5 张照片（本地上传）与每张照片标题
- **编辑后要保留在浏览器缓存里**，但 **刷新页面需要清空**（即：不跨刷新持久化）

## 方案选择
### 为什么不用 localStorage
`localStorage` 会跨刷新/重开浏览器长期保存，不符合“刷新清空”。

### 为什么选 sessionStorage + beforeunload 清理
使用 `sessionStorage` 保存编辑状态，优点：
- SPA 内部路由切换（不刷新）仍可保留
- 关闭标签页/刷新时可通过 `beforeunload` 同步清理，达到“刷新清空”的效果

实现要点：
- 进入页面时读取 `sessionStorage`（如果存在）
- 每次编辑变更时写入 `sessionStorage`
- `beforeunload` 时 `removeItem`，确保刷新后为空

当前缓存字段建议保持显式、可向后兼容（新增字段不影响旧缓存）：
- `customTitle`
- `customSubtitleFormed`
- `customSubtitleChaos`
- `photoConfigs`

## 本地图片上传如何缓存
浏览器缓存里不能直接存 `File` 对象：
- 采用 **DataURL（base64）** 存入 `sessionStorage`
- 为避免超出 `sessionStorage` 容量（常见约 5MB），上传时对图片做一次压缩：
  - `canvas` 缩放到最大边 1024
  - 优先导出 `image/webp`，不支持则回退 `image/jpeg`

## 稳定性建议
- 让“图片在树上的位置”与“slot index”绑定，编辑/换图时不随机重算位置，避免视觉跳变。
