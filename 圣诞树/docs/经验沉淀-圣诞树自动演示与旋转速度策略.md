# 经验沉淀：圣诞树“自动演示(autoPlay)”与旋转速度策略

## 背景 / 现象
- 自动演示的核心逻辑是：**树持续旋转**，当某张照片转到相机正前方时暂停旋转，推进相机观看，再拉远并继续下一张。
- 如果用户把旋转速度调得很低（例如默认较慢），会导致自动演示在 `WAITING` 阶段等待很久，看起来像“卡住”或“没在播”。

## 方案
- 自动演示开启时：将 `rotationSpeed` 临时拉满（当前 UI slider 上限为 `2`），加速对准/轮播。
- 自动演示停止时：将 `rotationSpeed` 恢复到初始默认值（避免停止后仍然转得过快导致眩晕）。

## 实现要点
- 把策略放在页面级状态（`ChristmasPage`）里监听 `autoPlay`，统一控制 `rotationSpeed`：
  - `autoPlay = true` → `rotationSpeed = 2`
  - `autoPlay = false` → `rotationSpeed = 0.3`（默认值）

## 小结
- **自动演示依赖“树旋转角度”**，因此需要和旋转速度联动，否则体验不稳定。
- 若未来增加“自动演示结束后恢复到用户播放前速度”，可改为在开启时记录旧值并在停止时恢复。
